# prototipos — vitrine alfa do site do Lab Escola 3D

Protótipo navegável do site do **Lab Escola 3D (LE3D)**, projeto de extensão da UFRJ que reúne materiais educacionais gratuitos para professoras da rede pública: jogos, oficinas, atividades e manuais, para baixar, imprimir e adaptar.

- **No ar:** https://labescola3d.github.io/prototipos/
- **Site oficial:** https://labescola3d.rio.br/

## Para quem vai trabalhar aqui

| Arquivo | Para quê |
| :-- | :-- |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | como trabalhamos: Issue, ramo, pedido de junção, revisão e junção |
| [`AGENTS.md`](AGENTS.md) | regras para qualquer agente de IA que mexa neste repositório |
| [`PARA_IA.md`](PARA_IA.md) | identidade visual e princípios das telas, para IAs que prototipam sem acesso ao repositório |
| [`docs/decisoes/`](docs/decisoes/) | o que foi decidido e por quê |
| [Issues](https://github.com/labescola3d/prototipos/issues) | o que está em andamento |

Juntar na `main` publica a vitrine em cerca de um minuto.
